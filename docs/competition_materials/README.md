- `🎤 推荐话术（以医院本地部署为核心）.md` — suggested demo narration focused on hospital local deployment.
- `🏆 计算机设计大赛省级决赛答辩：AI-Agent 功能板块模拟问答题库.md` — simulated Q&A bank for the AI-Agent function section.
